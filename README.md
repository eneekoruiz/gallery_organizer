# Smart Gallery AI

Local media organizer for indexing, searching, and reviewing personal photo and video collections.

## What it does

- scans local folders and tracks new media
- groups faces and tags objects and scenes
- supports semantic search over the library
- keeps duplicate detection and review workflows local
- provides a Streamlit dashboard for curation

## Requirements

- Python 3.9+
- optional Tesseract OCR

## Run

```bash
pip install -r requirements.txt
streamlit run smart_gallery_v2/app.py
pytest
```
